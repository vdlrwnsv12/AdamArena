악몽 리허설 0.6.6 — 기본 선택지 표시 및 보스 방 도착 처리 수정

설치
게임을 완전히 종료하고 새 폴더에 압축을 푸세요.
그 폴더의 INSTALL.command 실행 후 같은 폴더의 PLAY.command로 켜세요.
메인 화면과 상태 창에 0.6.6이 표시되는지 확인하세요.
처음 시험할 때는 별도 저장본을 사용하세요.
기존 PLAY.command나 스팀 일반 실행은 이번 수정본을 실행하지 않습니다.

침대 선택지
별도 검은 사각형 패널, 임의 폰트 크기와 추가 캔버스를 제거했습니다.
게임의 기존 침대 대화 UI에서 원래 수면 항목 아래에 아담과 싸우기 — 악몽 리허설 항목을 그립니다.
기존 게임의 선택지 위젯, 글꼴, 배치와 선택 강조를 사용합니다.
휠 또는 위/아래 방향키로 고르고 F로 실행하도록 연결했습니다.
잠자기는 원래 수면 입력을 통과시키며, 악몽은 확인 입력을 소비하고 전투 입장을 요청합니다.
G는 꿈속 종료에만 사용합니다.
현재는 수면 선택지가 하나인 기본 침대를 대상으로 합니다. 다른 항목이 함께 있는 복합 대화는 변경하지 않습니다.
엔진의 실제 수면 액션은 보존하고 표시용 데이터에만 전투 항목을 추가합니다.
표시용 데이터는 매번 원본에서 새로 만들며 원본 대화 블랙보드의 선택지 배열을 교체하지 않습니다.
상태 창의 기본 게임 선택지 2개 표시를 확인할 수 있습니다.

선택 직후 바로 복귀하던 문제
이전 버전은 이동 요청을 낸 같은 갱신에서 집의 현재 위치를 경계 이탈로 판정할 수 있었습니다.
이제 이동 요청 후 해당 갱신을 끝내고, 이후 실제 좌표가 보스 방 근처인지 확인합니다.
도착 전에는 꿈의 경계 이탈 검사를 실행하지 않습니다.
대략 20초 동안 도착을 확인하지 못하면 이동 미완료 안내와 함께 복귀하도록 구현했습니다.
도착 후에는 바닥과 스매셔 소환 준비 안내가 나오며 바닥 준비를 기다린 뒤 소환을 요청합니다.
로딩 동안 위치를 반복해서 강제로 고정하거나 순간이동시키지 않습니다.

사이버웨어 용량
용량과 벌칙 계산은 0.6.5와 같습니다.
게임이 장착량에 맞춰 늘린 최대치에서 임시 초과 허용분을 뺀 후, 현재 보유한 엣지러너 특전이 실제로 허용하는 용량만 더합니다.
특전이 없으면 추가 허용분은 0, 있으면 특전 TweakDB 값(기본값 50)을 반영합니다.
초과 시 유효 운반 한도 1, 이동·사격 스태미나 비용 3배, 달리기·점프 제한을 같은 판정으로 적용합니다.
원래 운반 스탯과 다른 모드의 보정치는 영구 변경하지 않습니다.
보행은 원래 비용이 없으므로 미터당 3 스태미나 포인트를 적용합니다.
특전으로 다시 정상 용량을 확보하면 제한을 해제하고 현재 특전/버프가 반영된 운반 한도를 사용합니다.
장착 요구량 합계는 2초마다 갱신하므로 메뉴를 닫고 잠시 기다려 주세요.

특전·특성 초기화
캐릭터 특성 화면의 특전·특성 모두 초기화 버튼에서 확인창의 예를 선택한 경우에만 실행합니다.
레벨, 숙련 경험치와 장착 사이버웨어는 유지합니다. 자동 초기화하지 않습니다.

꿈속 전투와 복귀
확인된 미코시 보스 방으로 이동해 보스용 스매셔를 소환합니다.
패배하면 치명상을 막고 입장 전 침대 곁 위치로 복귀하도록 구현했습니다.
격파 후 G로 종료하며 전투 중에도 G로 중단할 수 있습니다.
체력과 스태미나는 입장 전 값으로 복원합니다.
보호와 저장 잠금은 트레이닝 중에만 적용합니다.
실제 눕고 일어나는 애니메이션과 한국어 V 입장 음성은 아직 없습니다.
탄약, 소모품과 경험치는 별도로 되돌리지 않습니다.
보관함 전시와 창문 관련 코드는 수정하지 않았습니다.

문제 확인
침대에서 2초 기다린 뒤 ESC → 악몽 리허설 상태 확인을 열면 용량과 기본 UI 생성 상태가 나옵니다.
이동에 실패하면 화면 위의 안내 문구도 함께 알려 주세요.
컴파일 실패 시 state/compile.log, 실행 실패 시 state/play.log와 state/game.log를 보내 주세요.

검증 범위
사용자의 맥 2.5 원본 캐시에 대해 공식 redscript 0.5.32 소스로 빌드한 Linux scc로 컴파일했습니다.
생성 결과를 다시 불러와 단일 파일로 역컴파일하고 기본 게임 선택지 구성과 도착 확인 코드가 연결되는지 확인했습니다.
최종 소스의 순수 도착 판정 함수를 추출해 대기/도착/높이 차이/시간 초과 8개 경우를 검사했습니다.
수정하지 않은 0.6.5 용량 계산과 코드가 일치하는 것도 확인했습니다.
배포 도구는 기존 공식 macOS ARM redscript 0.5.32입니다.
실제 맥에서 두 항목의 표시, 입력과 원래 수면 간 충돌 여부, 이동/소환/복귀 및 벌칙 동작은 아직 미검증입니다.
컴파일 및 판정 검사 성공과 실제 게임 성공은 다릅니다.
게임 원본 캐시를 교체하지 않는 별도 실행 방식입니다.
