악몽 리허설 0.6.7 — 키메라 제작 모드 분해·코어 반환 추가

설치와 실행
게임을 종료하고 이 ZIP을 새 폴더에 압축 해제하세요.
새 폴더의 INSTALL.command를 실행한 뒤 같은 폴더의 PLAY.command로 켜세요.
스팀에 로그인한 상태에서 실행 터미널을 열어 두세요.
메인 화면에 0.6.7이 표시돼야 이번 수정본입니다.
게임 원본 캐시는 교체하지 않으므로 스팀 일반 실행이나 옛 PLAY.command에는 이번 코드가 적용되지 않습니다.

키메라 코어로 만든 무기 부품 분해
무기에 끼워져 있다면 먼저 해당 부품을 빼세요.
가방에서 그 부품을 선택한 뒤 게임의 기존 분해 입력을 사용하세요.
확인창이나 수량 선택창이 뜨면 기존 방식대로 진행하세요.
완료하면 제작 부품 1개당 제작에 사용되는 키메라 코어 1개를 반환하도록 구현했습니다.
반환한 코어를 이용해 다시 제작할 수 있도록 이미 배운 키메라 제작법의 숨김도 해제합니다.
인벤토리에서 부품이 실제로 줄어든 수량만큼만 코어를 지급합니다.
분해 미리보기, 확인 취소, 중복 요청, 수량 부족은 코어를 지급하지 않습니다.
일반 무기나 다른 제작 부품의 분해 결과는 변경하지 않습니다.
비활성 전시용 코어의 수량과 집 전시 상태는 변경하지 않습니다.
게임의 ChimeraMod 태그와 실제 제작법을 읽습니다. 활성 코어의 아이템 번호를 임의로 추정해서 지급하지 않습니다.
다른 모드가 제작법을 바꾸어 재료가 하나/수량 1인 구조가 아니면 해당 부품은 분해를 허용하지 않습니다.
퀘스트 보호, 해제 금지 태그와 장착 중 보호는 유지합니다.

침대와 악몽 전투
0.6.6의 기존 침대 UI, 보스 방 도착 대기와 전투 코드를 그대로 유지합니다.
기본 침대에서 잠자기 / 아담과 싸우기 — 악몽 리허설을 선택합니다.
휠 또는 위/아래 방향키로 고르고 F로 실행합니다. G는 꿈속 종료에만 사용합니다.
원래 잠자기 항목은 기본 게임의 수면 입력을 통과시킵니다.
패배하면 입장 전 침대 곁 위치로 복귀하고, 승리 후 G로 종료합니다.
입장 전 체력과 스태미나를 복원합니다. 탄약·소모품·경험치는 되돌리지 않습니다.
실제 눕고 일어나는 애니메이션과 V 입장 음성은 아직 추가하지 않았습니다.

애니메이션 연결용 침대 파일 수집
READ_BED_ASSETS.command를 실행하면 기본 게임 아카이브에서 H10 침대 장면과 관련 파일만 복사합니다.
이 폴더에 생긴 bed-assets-날짜-시간.zip을 이 채팅에 첨부해 주세요.
게임 설치 폴더, 실행파일, 원본 캐시와 세이브는 변경하지 않습니다.
자동 업로드나 인터넷 접속은 하지 않습니다.
모드 폴더의 아카이브는 제외하며 원본 아카이브에서 지정한 경로만 읽습니다.
게임의 압축 조각을 그대로 모으는 방식이라 맥에 압축 해제 도구를 따로 설치하지 않아도 됩니다.
Python 3가 필요합니다. 찾을 수 없다는 메시지가 나오면 그 메시지를 알려 주세요.
압축 조각은 파일당 최대 32 MiB, 전체 최대 128 MiB로 제한합니다.
일부 파일을 못 찾거나 읽지 못하면 ZIP 안의 manifest.json에 기록합니다.
현재 수집기 검사는 합성 아카이브를 사용했습니다. 실제 맥 게임 아카이브에서는 아직 미검증입니다.

특전·특성 초기화와 사이버웨어 용량
0.6.6과 동일합니다. 캐릭터 화면의 특전·특성 모두 초기화 버튼에서 확인한 경우에만 초기화합니다.
레벨, 숙련 경험치와 장착 사이버웨어를 유지하며 자동 초기화하지 않습니다.
게임이 장착량에 맞춰 임시로 늘린 한도를 제외하고 현재 특전이 실제로 허용하는 용량으로 판정합니다.
초과하면 유효 운반 한도 1, 이동·사격 스태미나 소모 3배, 달리기·점프 제한을 적용합니다.
특전을 다시 찍어 정상 용량이 되면 현재 특전·버프가 반영된 운반 한도로 복원합니다.
장착량 갱신은 최대 2초 정도 걸릴 수 있습니다.
보관함 전시와 창문 관련 코드는 수정하지 않았습니다.

검증과 문제 확인
제공된 맥 2.5 원본 스크립트 캐시에 대해 공식 redscript 0.5.32 기반 컴파일과 결과 재검사를 통과했습니다.
분해 수량 계산 9개 경우와 수집기 합성 아카이브 검사 8개를 통과했습니다.
게임에서 분해 버튼 표시·코어 반환·재제작이 실제로 작동하는지는 아직 미검증입니다.
처음에는 별도 저장본으로 확인하세요.
컴파일 실패 시 state/compile.log, 실행 실패 시 state/play.log와 state/game.log를 보내 주세요.
