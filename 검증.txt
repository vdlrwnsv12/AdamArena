변경 범위 확인
0.6.6 소스의 버전 문구만 0.6.7로 바꾼 원문이 그대로 보존되고, 그 뒤에 키메라 기능만 추가됨 확인
기존 침대 UI, 도착 처리, 전투, 특전·특성 초기화와 용량 벌칙 코드 변경 없음
실제 눕기·기상 애니메이션은 미연결. 실제 H10 장면 확인을 위한 읽기 전용 수집기 포함

분해 수량 판정
최종 RemovedCount 소스의 함수 본문을 추출하고 if 문 괄호와 Min 표기만 C++ 형식으로 바꿔 실행
9개 경우 통과: 단일 제거, 취소/실패, 여러 개, 일부 제거, 빈 가방, 수량 증가, 0 요청, 잘못된 음수 수량, 요청 수량 상한
이는 순수 함수 검사이며 엔진 인벤토리 트랜잭션의 실제 성공 검사가 아님
